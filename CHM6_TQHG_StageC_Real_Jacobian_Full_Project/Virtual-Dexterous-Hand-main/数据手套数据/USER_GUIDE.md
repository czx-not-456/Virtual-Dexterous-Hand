# multi_teleop 用户使用说明

<p align="center">
  <img src="ui/assets/ZKGJ.jpg" alt="中科硅纪 CasiaHand Robotics" width="280">
</p>

multi_teleop 将中科硅纪数据手套的手部传感数据映射到 MuJoCo 仿真手和真实机械手。建议首次使用者严格按照“基础标定 → 仿真确认 → 实机低速测试”的顺序操作。

本文档用于指导普通用户使用数据手套完成手部仿真、标定和真实机械手遥操作。

## 1. 使用前准备

### 系统与设备

- Windows 10 或 Windows 11（64 位）。
- 数据手套及其接收器/连接线。
- 进行实机遥操作时，还需要机械手、电源和对应的 USB 串口设备。
- 建议首次使用时先完成仿真测试，确认动作方向和幅度正确后再连接实机。

### 安全注意事项

- 实机首次测试时不要抓持物体，并确保机械手周围没有人体或易损物品。
- 启动遥操作前，让手套和机械手都处于自然张开状态。
- 发现关节方向错误、快速抖动或异常卡阻时，立即点击“停止遥操”；必要时切断机械手电源。
- 不要在遥操作运行期间拔出串口设备或关闭手套。

## 2. 安装包说明

请保留完整的 `multi_teleop` 文件夹，不要只复制其中的 EXE。正常目录结构如下：

```text
multi_teleop/
├─ multi_teleop.exe       启动程序
├─ _internal/             程序运行库，请勿移动或删除
├─ config/                配置和实机映射
├─ mod/                   MuJoCo 仿真映射
├─ models/                手套专属校正模型
├─ calib/                 手套基础标定文件
├─ records/               标定和记录数据
└─ 用户使用说明.md
```

`config`、`mod`、`models` 和 `calib` 中包含当前设备的映射与标定结果。更换安装包或重新标定前，建议先备份这些文件夹。

## 3. 推荐操作流程

### 第一步：启动软件

双击 `multi_teleop.exe`。主界面出现后再连接和操作设备。

如果 Windows 首次启动较慢，请等待数秒，不要连续双击启动多个实例。

### 第二步：连接数据手套

1. 打开数据手套并连接接收器。
2. 点击主界面的“选择设备”。
3. 在设备列表中选择实际使用的手套。
4. 确认后等待主界面显示实时传感器数据。

如果使用两只手套，请确认左右手和设备序列号对应正确。软件会根据手套序列号和左右手匹配各自的校正模型。

### 第三步：完成手套基础标定

每次重新佩戴手套，或手套数据明显偏移时，建议重新标定。

新标定流程：

1. 点击“重置标定”。
2. 将手指完全张开，再自然握拳，反复完成几次完整开合。
3. 动作过程中尽量覆盖每根手指的正常活动范围。
4. 点击“停止标定”固定结果。
5. 如需下次复用，点击“保存标定”。

已有标定文件时，可以点击“读取标定”并选择对应文件。标定完成后，仿真、记录和遥操作按钮才会启用。

### 第四步：先进行仿真检查

1. 点击“启动仿真”。
2. 选择需要测试的手模型。
3. 缓慢活动每根手指，检查仿真手的方向、幅度和稳定性。
4. 重点检查张开、捏合、握拳以及各手指单独弯曲。

如果动作明显不准确，请先停止后续实机操作，再检查基础标定或重新进行仿真标定。

### 第五步：开始实机遥操作

1. 正确连接机械手和电源，并确认串口未被其他软件占用。
2. 点击“开始遥操”。
3. 勾选要控制的机械手型号。
4. 选择该机械手对应的映射文件、串口和 Hand ID。
5. 可以使用“自动检测串口”辅助识别设备，但仍需人工确认型号和端口是否匹配。
6. 点击“确认”后，从小幅、缓慢动作开始测试。
7. 使用结束后点击“停止遥操”，等待机械手返回初始位置，再关闭电源或拔出设备。

单只手套也可以控制另一侧机械手，但必须选择正确的目标机械手、映射文件和左右手配置。

## 4. 仿真标定与学习

普通使用中，如果现有映射效果正常，不需要重复训练。以下操作适用于更换手套、重新佩戴后偏差较大，或需要建立新映射的情况。

### CH-M6 自动仿真标定

1. 连接并完成手套基础标定。
2. 点击“仿真标定”。
3. 确认目标模型为 `CH-M6`。
4. 按界面顺序完成六个统一预设姿态：
   - 张开
   - 对食指
   - 对中指
   - 三指捏
   - 半握
   - 握拳
5. 仿真手摆出目标姿态后，使用者跟随参考姿态并保持稳定，等待软件完成记录。
6. 全部姿态完成后，由软件自动训练并保存映射。

训练过程中不要快速切换姿态，也不要移动手套在手上的佩戴位置。训练结果与手套序列号及左右手绑定，更换手套后应使用对应手套重新标定。

### CH-3 三指学习

CH-3 的机械结构和训练姿态与 CH-M6 不同，必须使用主界面的“三指学习”，不能使用 CH-M6 的标定结果替代。

按界面参考图依次完成姿态并保持稳定。学习结束后，软件只更新 CH-3 对应的仿真和实机映射。

### CH-M6 吸附姿态微调

该功能位于“设置 → CH-M6 → 吸附姿态微调”，仅建议调试人员使用。打开前需要先启动 CH-M6 仿真。

修改后应逐一验证对食指、对中指、三指捏和握拳，避免吸附过强影响手指自由运动。普通用户不建议修改已验证的吸附参数。

## 5. 数据记录

1. 完成手套标定后点击“数据记录”。
2. 正常完成需要记录的动作。
3. 点击“停止记录”。
4. 记录文件保存在安装目录的 `records` 文件夹中。

记录过程中不要关闭软件或直接拔出手套。

## 6. 常见问题

### 双击 EXE 后没有启动

- 确认运行的是完整安装文件夹中的 `multi_teleop.exe`，而不是单独复制出来的 EXE。
- 检查 `_internal` 文件夹是否存在，文件是否被安全软件隔离。
- 不要从压缩包内部直接运行，请先完整解压。
- 如果仍无法启动，可运行 `_internal/new_main.exe` 查看控制台错误，并将完整错误信息提供给维护人员。

### 出现 NumPy 或 `_multiarray_umath` DLL 错误

说明安装包不完整或使用了旧版本。请重新获取并完整解压最新安装包，不要从其他 Python 环境手动复制 DLL。

### 找不到数据手套

- 确认手套已开机、接收器已连接。
- 关闭其他可能正在占用手套的程序。
- 重新插拔接收器后，再点击“选择设备”。
- 无线手套请检查电量和连接状态。

### 仿真、记录或遥操作按钮不可用

这些功能需要先连接手套并完成“重置标定 → 手指完整开合 → 停止标定”。也可以通过“读取标定”加载有效的历史标定文件。

### 仿真动作幅度不正确或手指互相带动

1. 重新完成手套基础标定。
2. 确认当前加载的是该手套序列号和左右手对应的校正模型。
3. 对 CH-M6 重新执行六姿态仿真标定；CH-3 则使用“三指学习”。
4. 如果只有吸附姿态异常，再由调试人员检查吸附参数。

### 实机没有动作或动作方向错误

立即停止遥操作，然后检查：

- 机械手型号是否选对。
- 串口是否正确、是否被其他程序占用。
- Hand ID 是否与机械手一致。
- 映射文件是否属于当前机械手型号。
- 仿真中的动作方向是否已经正确。

### 仿真画面卡顿

- 关闭重复打开的仿真窗口和其他占用显卡的软件。
- 不要同时进行自动学习、数据记录和实机遥操作。
- 在设置中适当降低刷新频率后重新启动仿真。

## 7. 故障反馈信息

反馈问题时，请尽量同时提供：

- 数据手套型号、序列号和左右手。
- 机械手型号、串口和 Hand ID。
- 正在使用的映射文件名。
- 问题发生前的操作步骤。
- 完整错误截图或控制台输出。
- `_internal/Logs` 中对应时间的日志文件。
