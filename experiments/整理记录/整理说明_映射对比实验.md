# 映射方法对比实验：一组一目录整理说明

本次以用户提供的 `映射方法对比实验_清晰整理版_项目内部无压缩包(2).zip` 为输入，进一步把原先 `映射方法对比实验/` 中的五类混合目录拆成**10 个根目录下的独立实验文件夹**。每个文件夹都有 README、脚本、results。见 [`00_映射对比实验_从这里开始.md`](../映射对比实验导航.md)。

## 原来混在一起的内容如何拆分

- `glove_mapping` → 标定对比（实验03）和抓握任务对比（实验04）。
- `schemes_b_e` → 方案 B、C、D、E 的四组独立离线对比（实验05～08）。
- `stage_c` → 五方法 MuJoCo 对比（实验09，包含专属审计工具）和抓握稳定性对比（实验10）。
- Stage B 和静态/动态对比仍各占一个独立文件夹（实验01～02）。

## 兼容与安全

- `scripts/`、`experiments/` 及根目录的旧入口只保留轻量转发，主要代码在各实验文件夹维护。
- `src/`、`configs/`、`数据手套数据/`、`test/` 等共享依赖及历史审计结果不移动。
- 已有 Stage B、手套对比、方案 C/D/E 结果文件内容未改；没有重新运行 MuJoCo，也没有补造缺失结果。
- 仓库内部没有 ZIP/RAR/7Z 等压缩包；旧 TEQS 补丁 ZIP 早在上一版整理时已移除且未应用。
- 本次不是 GitHub 上的自动提交；建议从最新 main 创建独立分支、检查差异后提交，并确认 `v1.3.2` 标签未被占用。
