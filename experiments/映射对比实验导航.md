## 一键离线核心实验（从仓库根目录）

```powershell
python experiments/run_core_mapping_suite.py --dry-run
python experiments/run_core_mapping_suite.py --groups stageb,modules,spectrum --steps 24 --out outputs/mapping_core
```

新产物位于 `outputs/mapping_core/`：`manifest.json`、`paired_comparisons.csv`、`evidence_report.md`、各方法运行 CSV 和原始日志。

`--groups stageb` 可以单独跑鲁棒性消融，`--groups modules` 跑 B/C/D（同一份数据）；`--groups spectrum` 跑方案 E。`stagec` **不在默认脚本中执行**，需要在 MuJoCo 环境先用 `python scripts/run_stageC_mujoco.py --dry-run` 核对试验命令。

## 结论边界

- A、B、C、D、E 部分历史实验共享 24 帧、6 个预设姿态，非独立受试者/独立批次数据。重复方法或故障掩码不增加独立样本量。
- 离线指标是与**软件教师姿态标签**的误差，不能当作真实关节真值或抓握成功率。不同求解约束的直接映射基线也不完全等价。
- 新报告对同一姿态内部先平均，再对姿态组进行探索性配对 bootstrap；仅 6 个姿态组，**不能用区间显著性宣称泛化**。
- 运行时间受硬件、缓存和 Python 运行条件影响，不应拿单次历史 benchmark 作跨机器绝对性能结论。
- 阶段 C 物理消融结果**目前待验证**，不捏造不存在的实验数据。
