# 面向抓握任务的动作映射方法研究与对比实验季度报告

本报告涵盖 v1.2.0—v1.3.2 阶段的映射方法研究与实验体系建设，并补充 main 分支的工程整理工作。

## 一、项目执行的进展情况

上一阶段，项目已完成真实手套标定数据的离线接入，并能在 MuJoCo 中驱动 CH-M6 虚拟灵巧手。本阶段在已有平台上，围绕不同映射方法对任务动作的影响，以及传感器通道缺失时的映射可靠性开展研究。

v1.2.0 阶段主要扩展映射研究方案。针对捏取等动作中各关节对指尖任务影响不同的特点，项目梳理了任务自适应协同、目标可达性、输入可信度及任务效应谱等思路，形成方案文档、运行说明与配套验证材料，为后续方法选取和工程验证提供依据。

v1.3.0—v1.3.1 阶段重点完成 Stage C 工程集成。项目采用六维直接映射与四维协同映射作为两个专家模型：前者直接预测六维控制量，后者通过四个协同变量还原六维控制量。两个专家使用相同的历史训练数据和缺失增强条件，并以单独划分的历史记录进行风险及门控标定。在此基础上，集成根据 MuJoCo 当前姿态计算任务雅可比矩阵的接口，在任务方向与互补方向分别调节两个专家的贡献，加入显式通道缺失、恢复及安全回退机制，并开展软件层面的功能测试。

v1.3.2 阶段重点完善对比实验组织。项目将 Stage B 消融、静态与动态映射、手套标定及任务对比、各协同方案、Stage C 五方法与稳定性对比整理为十组独立实验，统一各组实验的运行入口、结果目录和说明文档。Stage C 五方法流程围绕同一条 360 帧捏合诊断轨迹设置正常、指定通道缺失及恢复条件，支持记录门控权重、指尖误差、接触比例和稳定性代理指标。随后，main 分支完成文件结构整理、重复文件清理及文档导航完善，提高代码与研究材料的可追溯性。

## 二、取得的成绩

项目形成了从研究方案梳理、专家模型构建、门控工程集成到分阶段对比的研究流程。方法比较同时关注离线映射误差与仿真任务指标，为分析映射输出如何影响指尖动作和物体接触提供了实验工具。

Stage B 离线消融为选择比较基准提供了定量依据。两个增强专家使用相同的 124 条历史记录训练，另用 66 条历史记录进行风险或融合参数标定，并在 24 条记录、6 种姿态上施加合成通道缺失开展诊断性复测。三路通道缺失时，以软件教师提供的六维控制量为参考，增强六维模型、增强四维协同模型和校准标量融合方法的归一化平均绝对误差分别为 0.086659、0.087601 和 0.086705。在这三种方法中，增强六维模型的误差最低，三者数值接近。该结果支持将公平增强的六维模型保留为主要比较基准，避免将不同训练条件带来的变化直接归因于降维或融合。上述指标描述软件参考标签误差，不代表真实关节跟踪或抓握精度；不同缺失掩码的重复也不构成新增独立动作样本。

Stage C 已形成六维专家、四维专家、仅任务门控、仅互补门控及双门控五种配置的配对实验入口。现有工程材料记录了无 MuJoCo 条件下的启动、CSV 日志、故障时序、恢复及安全回退测试，为进一步开展任务层面的公平对比提供了基础。十组实验的归档则将已有结果、执行脚本和评价说明按研究问题组织起来，便于复核和复现。

## 三、是否达到预期效果

对照本阶段“扩展映射方案、集成门控方法、建立多方法对比流程”的工作安排，项目已形成相应的方案材料、算法接口和实验组织结构，基本达到研究流程与工程建设方面的阶段预期。

离线对照进一步明确了强六维基线的作用，使后续研究能够在统一训练条件和评价口径下考察协同与融合的适用性。当前成果支持多方案比较及故障处理流程的研究，不据此认定双门控已优于强单专家。其任务效果将结合 MuJoCo 配对输出和更多独立动作进行评价，接触与局部稳定性指标也将与完整物体操作效果分别解释。

## 四、项目开展过程中存在的问题

现有诊断数据集中于有限姿态和单条捏合轨迹，对连续动作、不同物体初态及跨批次输入的代表性有限。同一轨迹的重复运行不能替代独立试验，部分保持阶段接触比例接近上限，也使方法差异较难充分体现。

目前的通道缺失由程序指定，仅作用于映射层输入有效性，不代表整套手套信号链的实际失效。真实设备中的卡死、漂移和间歇丢帧具有不同特征，需要结合连续采集数据研究识别及恢复策略。此外，软件教师标签与指尖接触、相对手掌稳定性代理各有评价边界，需要通过实际关节测量和更丰富的操作任务建立对应关系。

## 五、项目后期具体工作计划

下一阶段首先围绕现有捏合诊断轨迹开展五方法配对对照，统一输入、缺失通道、故障起止时刻与下游控制器，归档运行配置、逐帧日志及汇总表。重点检查实际任务投影的数值秩、两类门控的作用，以及故障期间和恢复后的指尖误差、接触比例与稳定性代理表现。

随后补充独立屈指、连续捏合和圆柱包络等动作，设置不同物体初始位置并采集多次独立试验记录。在实验前明确评价指标与成功判据，分别统计故障窗口接触保持、恢复后姿态误差及求解耗时，形成按任务与故障条件划分的对比结果，避免将重复帧作为独立样本。

在此基础上，结合真实手套连续采集和 CH-M6 参数核验，整理数据批次、输入异常与关节响应记录，逐步明确六维直接映射、低维协同映射和双门控融合各自适用的任务条件。同步维护实验导航及结果说明，形成可追溯的数据、配置、日志和分析材料。
