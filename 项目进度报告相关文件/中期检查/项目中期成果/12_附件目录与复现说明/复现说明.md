## 一 独立核验保存的数据

在本文件所在12目录打开PowerShell，使用有NumPy、Pandas及Pillow的Python环境：

```powershell

```

若依赖缺失，在所选环境安装：`python -m pip install numpy pandas Pillow`。视频解码完整性检查另需OpenCV：`python -m pip install opencv-python`。这些是依赖说明，本次整理不会自动安装。
