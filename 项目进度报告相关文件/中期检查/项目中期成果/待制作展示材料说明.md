## 使用注意

1. 本次仅创建目录并复制参考资料，未运行仿真、录屏、绘图或新增实验结论。所有“待完善材料”文件夹在创建时均为空。
2. MuJoCo 参考结果属于 2026-10-08 历史基线，不代表当前版本复测成绩；PINCH 接触成功不等于自由物体稳定抓握，历史稳定指标也不能直接与后续 StableGrasp-v2 混用。
3. Stage B 是软件教师标签的离线诊断误差，不是物理抓握性能；融合或降维方法没有全面领先的结论。
4. 历史成果梳理中可能有已过时的路径或项目状态，制作计划页时需结合当前 README 和原有实验结果核对。
5. 复制的 Python 脚本仅作为代码参考，其依赖仍在原项目中，应从项目根目录运行原脚本；不要将这些参考副本当成独立可运行工具。历史命令也需核对当前路径后使用。
6. README 和报告按原文保留，内部部分链接在复制位置可能无法直接打开。原始来源与 SHA-256 见同级《待制作材料_参考资料来源清单.csv》。原项目“数据手套数据/”目录未读取或复制。
