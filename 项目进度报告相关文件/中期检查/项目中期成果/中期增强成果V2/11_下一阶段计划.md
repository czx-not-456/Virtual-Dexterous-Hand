# 当前问题与下一阶段计划

| 现有证据 | 尚待解决的问题 | 下一阶段验收建议 |
|---|---|---|
| PINCH 3次接触代理均通过、稳定代理均未通过 | 拇指与食指接触保持 | 固定评估口径，至少10次独立随机物体初始位姿，记录稳定连续帧、物体漂移及失败原因 |
| WRAP 3次稳定代理通过 | 尚未验证持续持物、提举 | 增设物体自由运动及持物/提举评价，明确成功判据与失败记录 |
| 12台设备留出六类静态姿态识别 | 缺少独立被试和连续动态动作 | 采集多被试连续转换动作，按被试及采集批次隔离划分 |
| 人为屏蔽5路传感器可用距离法96.84% | 未验证真实缺失、漂移和噪声混合故障 | 记录真实断连和漂移片段，统一故障注入条件进行复测 |
| 合成序列EMA滤波对比 | 滤波响应延迟与跟踪精度权衡 | 利用同步采集的动态参考轨迹验证实时滤波 |
| 历史处理延迟P95约110—133ms | 不支持严格60Hz实时处理 | 分模块计时、定位优化瓶颈，改善P95后在相同条件重新Benchmark |

上述为建议验收方案，非已经完成的实验指标。
