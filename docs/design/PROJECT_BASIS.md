# 项目依据与 v0.2 实现边界

本工程依据项目申报材料中“数据手套输入—姿态解算与特征建模—动作映射—虚拟验证”的总体闭环搭建。

v0.2 重点对应虚拟交互验证层：继续使用 Python 完成数据处理、姿态解算、意图识别和映射优化，以 MuJoCo 承担运动学、接触与抓取场景验证，并为后续 Unity 展示预留接口。

## 当前已经实现

- Mock 数据手套连续输入；
- 面向个体差异的量程标定框架；
- 滑动平均与输出低通；
- 15 关节姿态参数化；
- 底层关节 / 中层协同 / 高层 PINCH-WRAP 语义；
- 拓扑映射 + 末端误差 + 平滑项 + 协同惩罚；
- 意图驱动动态权重优化；
- v0.2 MuJoCo 仿人手和抓取场景；
- 延迟、RMSE、速度稳定性 CSV 记录。

## 当前尚未得到材料支持、因此没有伪造的内容

项目材料没有提供：

- 实验室数据手套真实 SDK / 串口或网络协议；
- 真实传感器通道编号与量程；
- 目标灵巧手官方 MJCF / URDF；
- 真实关节限位、减速比、欠驱协同参数；
- 最终实验标定得到的 PINCH / WRAP 阈值。

因此 v0.2 的手模型仍属于工程验证模型，不能表述为目标实体灵巧手的精确数字孪生。
