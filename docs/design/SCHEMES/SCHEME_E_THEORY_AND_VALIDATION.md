# Scheme E / TEQS — Task-Effect Quotient Synergy with a Dual Output Shield

**研究状态（2026-10-15）**：候选新方法及工程原型；数学命题已在其限定模型下测试，尚未通过真实接触、连续人手动作、异构机器人或硬件实验验证；不声称文献意义上的绝对首创。

## 1. 核心研究问题

输入 `s∈R^15`、监督标定参考 `u_ref=g(s)∈R^6`，CH-M6 软件驱动假设 `q=C u∈R^11`。目标是既不丢失当前指尖任务有用的控制模式，又在已知软件耦合和关节速度/位置边界内使用尽可能少的活动方向。**11 个位置执行器的存在不代表真实机械传动只有 6 个自由度；C 是项目软件配置假设。**

传统 PCA 优化的是采集姿态方差而不是某个时刻的机器人指尖任务；方案 C/D 引入任务可达性和残差，但缺少精确的局部模式选择恒等式、风险组合的有限精确搜索，以及最终滤波/限速之后的任务与参考双重校验。

## 2. 提议的理论结构

### 2.1 任务效应等价与正则化“提升”

令 `f(u)=RobotFK(Cu)` 表示当前任务选定指尖的堆叠坐标（单位 m）；`J_t=∂f/∂u` 是已经吸收6→11映射的雅可比（尺寸 `3n_f × 6`）。在严格的一阶物理任务下，定义控制等价 `u_1~u_2` 当 `J_t(u_1-u_2)=0`，商空间 `R^6 / ker(J_t)` 忽略对当前任务一阶不可见的方向。为防止忽略其他手指动作与传感器标定参考，实际算法采用正则化“提升”：

```
A_t = [ W_task^(1/2) J_t ; lambda_c I_6 ],
b_t = A_t (u_feasible - u_prev),  lambda_c > 0.
```

`u_feasible` 是参考控制 `g(s)` 在**本帧速度/位置约束盒**的分量投影。该控制保持项使 A 满列秩，因此算法使用的是**正则化提升后的任务谱**，不能误称 A 自身仍有非平凡核。

### 2.2 任务效应谱（Task-Effect Spectrum）

设控制代价度量 `M ≻ 0`，包括一个**弱**的人手姿态先验；若且仅若噪声被独立标定，可以加入真正的传感器噪声代价（默认关闭）。计算

```
A M^{-1/2} = U diag(sigma_1,...,sigma_6) V^T,
d_i = M^{-1/2} v_i,
a_i = u_i^T b,
g_i = a_i^2 .
```

算法按 `g_i`（**当前任务期望效应**）从大到小排序，而不是按 PCA 方差或单纯按奇异值排序。候选 k 个方向的无约束重建是

```
Delta u_k = sum_{i in S_k} d_i (a_i/sigma_i).
```

**命题 1（固定谱字典内的精确局部最优性）。** 对任意固定 `A,M,b`，且 `A` 满列秩，给定任意大小为 k 的谱方向索引集 S，最小一阶任务误差平方等于

```
min_c || b-A D_S c ||_2^2 = ||b||_2^2-sum_{i∈S}g_i.
```

因此取前 k 个最大 `g_i` 的方向，使**这一固定、度量正交的任务谱字典内**的线性误差最小；最小满足 `sqrt(||b||²-sum(g_i)) ≤ epsilon` 的 k 可以逐项检查找到。

**证明要点**：`A d_i = sigma_i u_i`，各 `u_i` 两两正交；投影定理/Pythagoras 等式给出上述恒等式。这是对经典 SVD 投影定理的本项目**新问题表述与具体用途**，不能声称发明了新的 SVD 定理，也不能声称任意 k 维空间的全局最小自由度。

### 2.3 有校准条件时的最小基数鲁棒选模

若另有经独立实验校准、能覆盖真实误差的椭球

```
E = {eta: eta^T Sigma_u^{-1} eta ≤ rho²},
P_S = D_S D_S^T M
```

则对**局部线性投影误差**满足

```
max_{eta∈E} || A P_S eta ||_2 = rho || A P_S Sigma_u^{1/2} ||_2
```

（非满秩时使用合适的椭球支持和伪逆定义）。由三角不等式可得条件局部误差界 `R(S) = e(S)+rho ||A P_S Sigma_u^{1/2}||_2`。

**命题 2（离散谱字典内的精确最小可行基数）。** 在固定谱字典、阈值 `e(S) ≤ ε` 和 `R(S) ≤ ε_risk` 下，枚举 6 个方向的 63 个非空子集，按 |S| 升序返回首个满足所有判据的集合，则其 |S| 是**有限谱字典内的最小可行基数**。

这只是有限搜索的正确性，不是非线性、硬件或概率覆盖的全球保证。默认 `risk_policy: diagnostic`；项目附带姿态内代理协方差没有独立校准，程序默认禁止把该代理直接作为“已校准风险约束”。

### 2.4 最终输出双重护栏（Dual Output Shield）

算法先在6维软件空间计算满足 `lo_t ≤ u ≤ hi_t` 的候选，再经过主程序的可选伺服/滤波处理**之后**，使用真正将送入机器手的 `u_out` 复核：

```
E_tip(u_out) ≤ E_tip(u_feasible) + epsilon_task,
|u_out,i-u_ref,i| L_i ≤ |u_feasible,i-u_ref,i| L_i + epsilon_encoder_deg,
q_out = C u_out,
lo_t ≤ u_out ≤ hi_t.
```

只要任一误差判据失败，就发送同样符合盒约束的 `u_feasible`。`L_i` 是6路参考控制的角度上限（度）。

**命题 3（执行前的模型相对不退化）。** 在 `f=RobotFK∘C` 被正确执行、最终状态与两个候选都用相同 `f`/目标评价、后处理没有进一步篡改 `q_out` 的情况下，最终指令确定地满足上列全部检查。它是“相对于同样受限速约束的6维参考”的**软件模型输出证书**，不证明真实人手误差、机械手实际跟踪、接触力或碰撞安全。

注意：已有执行器耦合系数未经真机传动标定，因此安全硬件实施前必须确认 C 的真实物理含义。

## 3. 与 D 的实质区别

- 不再按人手 PCA 方差保留方向；PCA 仅提供弱正则度量，方向由 `J_t` + 期望任务变化联合确定。
- 依据解析式得到**当前任务**各方向贡献；约束允许时以最小模式数描述目标。
- 可选椭球模式不是“给 k 加一个风险惩罚”，而是最多63子集的有限精确**基数**决策；只在协方差确有验证时允许启用。
- 同时验证**任务空间输出误差**和**对原始手套标定输出的偏离**，复核时刻放在最后一次后处理之后。
- 6→11耦合与本帧关节速度通过6维分量盒执行；可选小规模凸二次型细化（默认关闭，以保证低延迟）。

## 4. 24帧离线重放结果与对照边界

运行 `python experiments/实验08_任务效应谱方案对比/benchmark_task_effect_spectrum.py`。数据仅有6类预设姿态标签；24帧里没有真实接触与实测机械手关节角。**此处 MAE 是软件输出的6个主控制关节与预设姿态标签之间的误差。** 此结果不是“真实人手→机器人末端精度”。

见 `experiments/实验08_任务效应谱方案对比/results/schemeE_paired_comparison.json`；在同一运行机器上，离线重放的一组结果为（耗时可能因机器或系统负载波动）：

| 模式 | 标签 MAE (°) | 优化中位 (ms) | 管线 P95 (ms) |
|---|---:|---:|---:|
| 原始11关节直接映射 | 15.39 | 27.28 | 46.91 |
| 固定4维 PCA | 20.85 | 13.84 | 38.21 |
| 方案 C | 20.58 | 39.62 | 50.91 |
| 方案 D | 20.26 | 43.09 | 48.22 |
| **方案 E** | 16.52 | 5.41 | 6.78 |
| E 同限速、无谱6维参考 | 16.48 | 5.61 | 7.21 |
| E + 原低通滤波 | 16.48 | 5.56 | 7.32 |

**关键负面消融：E 的标签误差并没有优于“同样限速、但完全没有谱降维”的6维可行参考（16.48°）；其标签改善主要来自分量限速与参考控制保护，而不是谱算法本身。** 原始直接映射的标签 MAE 更低（约15.39°），但它没有维持当前6→11软件耦合关系（最大偏差约0.247 rad）；两者可行空间不同，不能据此得出真实机械性能高低。D 与 E 默认低通滤波策略不同，所以不能把整体耗时/误差变化全部归因于谱选模；E 的低通滤波消融单独给出。

在这24帧里，E 的主要协同选维经常为4～5个，但**最终输出真正少于6个谱方向的帧只有4/24（16.7%）**；有约 9/24 帧在优化内部退回到可行6维参考。因此该数据不能证明广泛任务具有显著低维优势。上述帧也不独立，不能进行有说服力的显著性推断。控制时间在此测试机上约6 ms，不代表真实部署60Hz的最坏情况上界。

## 5. 后续必须做的可证伪实验

1. **连续动作**：至少新增独立屈指、双指捏合、三指捏合、球/圆柱抓取的连续时序以及分受试者/设备独立测试；避免六类重复标签导致的虚高训练结论。
2. **标定**：真实关节编码器、6→11传动矩阵、传感器原位静态噪声、标定重采样与置信覆盖率。
3. **切换和接触**：在 MuJoCo 验证 `PINCH/WRAP` 接触丢失与恢复，统计真正参与接触恢复的新增谱方向比例，以及稳定抓取成功率/物体滑移。
4. **公平基线**：固定 PCA4、全6维、D、E、E无谱6维参考，均使用相同速度盒、相同观测输入、相同滤波策略、相同主指尖目标。实验应分开评估“工程限速改良”与“谱算法收益”。
5. **风险覆盖**：仅在有独立噪声标定数据时做椭球覆盖率及 chance-constraint 验证；统计未满足误差预算时保守回退的频次。
6. **计算复杂度**：单帧各阶段耗时、P95/P99 与 worst-case 60Hz期限违反率，必要时硬实时部署。
