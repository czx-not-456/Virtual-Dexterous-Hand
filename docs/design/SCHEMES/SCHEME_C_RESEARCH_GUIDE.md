# 方案 C：任务可达性门控的稀疏协同重定向（工程原型）

> 2026-10-14；基于原用户项目和方案 B。当前是**研究原型**，并非达到发表标准的已验证创新，也不是六电机硬件证明。

## 1. 研究问题与区别

输入为 15 维手套传感器，提供 6 维语义控制参考；CH-M6 配置 11 个关节/位置执行器。工程现有的 6→11 软件耦合矩阵 `C` 将 6 维归一化指令映为 11 个关节弧度 `q=C u`。

方案 B 尽管标称 `k=2..5`，仍同时优化 `k+(6-k)=6` 个连续系数。方案 C 不只改变变量正则化强弱，而是：

1. **在线任务条件化协同基**：在当前指令处使用 CH-M6 指尖雅可比与既有 PCA 先验构造 6×6 对称矩阵，分解出当前任务相关方向。
2. **真正最小维度门控**：通过当前目标在局部任务特征空间中的投影误差选择最小合格 `k`，第一阶段的非线性优化维数就是 `k`。
3. **事件触发的稀疏残差修复**：仅当第一阶段未达到预设局部任务阈值时，逐个开放互补方向（默认不超过 2 个）。每次必须改善局部误差，且不能恶化当前软件目标函数，才接受补偿。
4. **可选目标函数回退与命令安全**：如配置开启，低秩求解结果在已有非线性目标函数上不如可行 6D 参考时，回退到参考值；所有输出版保留配置的 6→11 线性联动与关节限位，独立在控制空间进行速率限制。

后两项的保证只针对**已设置的软件约束和目标函数**。雅可比下的投影误差是局部线性化估计，不是机器人抓取成功的数学保证。

## 2. 核心模型

设 `u∈R^6` 为归一化控制指令，`q=C u∈R^11`，
`x_tip(u)=FK(Cu)` 为指尖向量。当前命令 `u_prev` 对应局部雅可比

```
J_t = ∂ FK(Cu) / ∂u |_(u=u_prev)
```

局部任务协同核矩阵定义为

```
H_t = J_tᵀ J_t + α² B diag(λ) Bᵀ + β² d dᵀ/(dᵀd+ε)
H_t V_t = V_t Λ_t         (按特征值从大到小取列)
```

`B` 是项目已有的六维 PCA 全基；`λ` 是归一化训练方差，`d` 是当前可达控制方向。这个构造是**在线的模型驱动任务基**，没有声称在现有六类标签上学习出了独立、可泛化的任务专用潜空间。

把指尖局部位移和小权重的独立关节参考拼接成任务特征 `A_t, b_t`，6维最小二乘目标（按可行控制区间剪裁）为 `Δu_6`。对于不同的 `k`，计算：

```
e_k = min_z ||A_t V_t[:, :k] z - A_t Δu_6||₂
k* = min{k ∈ [k_min, k_max] : e_k ≤ max(ε_abs, ε_rel ||A_t Δu_6||₂)}
```

当没有满足阈值的候选时，选 `k_max` 并记录未达到的投影误差。

第一阶段：

```
min_z  F(C(u_prev + V_k z)) + λ_ref ||u_prev + V_k z - u_ref||²
s.t.  lower ≤ u_prev + V_k z ≤ upper
```

优化器求解维数**确实为 k**。

第二阶段，仅当第一阶段的局部任务误差高于阈值，才从互补方向逐个增补 `v_j δ_j`。优化目标加入 `λ₂||δ||₂²+λ₁ Σ sqrt(δ_j²+ε²)`，并设 `|δ_j|≤cap`。优化维数变为 `k+m`，其中 `m` 为实际开放的残差数、`m≤2`。补偿轴由当前剩余任务误差与各轴雅可比的相关性选择。

对于软件可行性：始终检查 `lower≤u≤upper`、`q=Cu`，之后的输出使用 6D 控制插值保持 11D 速率限制。**并未验证真实硬件驱动耦合、全身自碰撞安全、接触力安全或闭环稳定性。**

## 3. 文件

- `src/retargeting/reachability_synergy.py`：新算法；使用已有 `TaskAdaptiveSynergyMapper` 的标定解码、CH-M6 约束和有限差分指尖雅可比。
- `src/retargeting/optimizer.py`：将人手目标指尖位置传给新方法，输出诊断。
- `src/main.py`：新增 `--reachability-synergy` / `--reachability-config` 开关与 CSV 列。
- `configs/reachability_synergy.yaml`：默认算法参数，开启对直接可行参考的可选目标函数保护。
- `configs/reachability_no_residual.yaml`：去残差消融。
- `configs/reachability_fixed6.yaml`：同族配置的约束6D对照（并非原始11D）。
- `experiments/实验06_PCA与可达性协同对比/benchmark_reachability_synergy.py`：5组离线重放。
- `test/tests_20261012/test_reachability_synergy.py`：变量数、基变换、补偿、限位、耦合、速率、回退测试。

## 4. 运行方法（工程根目录）

```
python -m src.main --input glove --sim none --steps 24 \
  --latent-model configs/latent_chm6_adaptive.json \
  --reachability-synergy \
  --reachability-config configs/reachability_synergy.yaml \
  --latent-source sensor

python experiments/实验06_PCA与可达性协同对比/benchmark_reachability_synergy.py --steps 24

python -m pytest -q -k 'not canonical_trial_establishes_sustained_real_contact'
```

运行完整的 `--sim mujoco` 接触试验需要安装 `mujoco`。输入文件默认为工程原有 24 帧手套捕获数据。

## 5. 五组离线诊断（24 帧，全部 NEUTRAL）

> 指标为**最终输出6个主控制量相对于六类预设姿态标签**的 MAE；这不是实测的机器人关节跟踪精度，也不代表抓握成功率。用相同入口、同批24帧执行；不同主机耗时可能变化。

| 方法 | 预设标签 MAE（度） | 优化器中位耗时（ms） | 实际求解变量数 |
|:--|--:|--:|:--|
| 固定4维PCA | 20.85 | 约14.5 | 4 |
| 方案B（常开6系数） | 20.33 | 约25.4 | 6 |
| 方案C同族固定6维 | 20.37 | 约36.5 | 6 |
| 方案C无残差 | 21.25 | 约23.5 | 平均约4.79 |
| **方案C（默认，含回退）** | **20.58** | **约40.0** | **平均约5.08** |

方案 C 的非线性优化变量数分布：3维×1帧，5维×19帧，6维×4帧；7/24帧使用了“直接可行参考”保护回退，4/24帧使用了稀疏残差。使用回退时，求解器此前仍只优化 `k` 个变量，但**最终输出所在的命令空间恢复为6维**；两种维数必须在论文中分别报告。

测试结果：70 项不依赖 MuJoCo 的测试通过；3 项标准任务集成测试因执行环境缺少 `mujoco` 未能运行，不可当作“测试通过”。

**关键评价：方案 C 相比 B 显著改进了“真正低维优化+按需补偿”的算法结构，但本批数据未证明角度精度或计算速度优势。** 这一结论应写进实验章节，而不应被隐藏。详细 JSON：`experiments/实验06_PCA与可达性协同对比/results/reachability_5way_offline_24frames.json`。

## 6. 发表论文需要继续研究的突破口

当前代码属于可复现的原型，而非在学术意义上确立“原创性很高”的方法。下一阶段建议聚焦一个更清楚的待验证研究命题：

> 对15维带噪手套输入和约束6维控制指令的异构11关节机器人手，是否可以根据指尖可达性与输入可信度，自动选择满足任务误差容限的最小**实际优化维度**，并只在接触失败风险升高时开启稀疏独立补偿？

建议做的工作（尚未实现或验证）：

1. **连续动作与输入置信度**：多用户、多批次、独立屈指、捏合/抓握中间状态数据；为手套传感器建立噪声与漂移协方差，发展误差容限的概率/鲁棒版本。
2. **更高效率的局部约束Q P/解析梯度**：本版本SLSQP与数值雅可比延迟偏高，不符合60Hz（16.67ms）闭环预算，必须继续优化或采用两层不同频率控制。
3. **真正闭环接触自适应**：MuJoCo 接触观测或真机触觉压力信息参与残差触发；比较接触稳定性、指尖到物体距离和成功率，而非只比较标签拟合。
4. **公平消融和统计设计**：固定4、固定6、原始映射加相同耦合约束、B、C去Jacobian条件化、C去残差、C去保护，跨姿态/受试者的独立留出与置信区间。
5. **确认11执行器硬件含义**：当前`C`是软件映射假设。如果硬件真实11路独立，需重新设计高维可行空间，现有软件实验不可外推到真机。
