# CH-M6 方案D：可信度、局部可达性与接触反馈联合协同重定向

日期：2026-10-14。状态：**已实现/通过离线与纯算法测试的研究原型**，不是已经验证创新性的论文成果，也不是合格的真实硬件安全控制器。

## 1. 研究问题与真正的变化

输入数据手套 `s∈R^15`，对应6维语义参考指令 `u∈[0,1]^6`。11关节目标仍严格由项目既有软件耦合 `q=C u` 扩展；未建立11独立关节的驱动可控性，也没有测量真机机械传动比。

以前固定PCA只最大化6维预设标签的解释方差。方案C根据指尖任务Jacobian在线建立协同方向，但没有考虑传感器可靠性、接触状态，也没有验证最终非线性指尖误差。方案D增加：

1. **显式传感器协方差传播**：对同姿态重复采样的15路传感器建立协方差代理，结合回归残差代理，传播到6D编码空间；可切换sensor/control/blend，clip阶段使用局部导数。具有参数可追溯性，但代理不是独立测试测得的真实随机噪声。
2. **任务信息/输入可靠性共同决定协同基**：利用任务雅可比、全局PCA先验与任务方向构成在线Hessian代理，对不可靠控制方向进行加权；不是继续在一组固定PCA列中选取前k列。任务变换与控制动作实时关联。
3. **带条件风险界的最小活动维度**：在候选k中同时评估任务投影误差和二阶矩风险上界；使用`risk_policy: enforce`才允许风险代理参与选维/控制。默认`diagnostic`只记录风险，避免不可信代理造成不必要的性能劣化。
4. **观测接触状态门控**：基于前一帧真实仿真反馈建立 `UNOBSERVED/FREE/APPROACH/SECURE/LOSS_RISK` 状态；多帧去抖动，稳态关掉残差，接触丢失可在限定帧数内尝试释放互补轴。有限的接触指示不是可靠的力/滑移传感。
5. **非线性FK护栏**：对最终候选与耦合6D参考各做一次机器人正向运动学评估；如果候选的指尖RMS误差比参考大超过1mm，退回参考并明确计数。护栏是在滤波/速率限制**之前**检查，不是全轨迹精度或抓握安全保证。

## 2. 可复现数学定义

令编码器为`f(s)`，其对手套角度的局部导数为`G=∂f/∂s`，给定传感器及标签残差协方差代理：

```
Σ_u = G Σ_s Gᵀ + Σ_model
J_t = ∂FK(Cu)/∂u
H_t = J_tᵀJ_t + α² B diag(v) Bᵀ + β²ddᵀ/(dᵀd+ε)
```

`H_t` 在可信度激活模式下经正定对角可靠性权重作对称缩放，再分解得到正交任务基 `V_t`。控制为

```
u_t = u_prev + V_{t,k} z + N_t δ
q_t = C u_t
```

先只用k个`z`变量求解。必须补偿时才选择少数互补列加入`δ`，保持严格的6D软件控制限位，并在6D控制空间限速。

令`A`为拼接的任务指尖局部Jacobian及小权重控制先验，`b`为可行6D局部目标，`P_k=V_k V_kᵀ`。投影误差 `e_k=||A V_k (A V_k)^† b - b||`。风险上界是：

```
R_k = e_k + sqrt[tr(A P_k Σ_u P_kᵀ Aᵀ)/risk_alpha]
```

若真正扰动零均值、协方差不超过给定`Σ_u`，而手模型可视为局部线性，则 Markov/Chebyshev 给出 `Pr(||局部任务扰动+投影残差||≤R_k)≥1-risk_alpha`。**这只是在上述理想假设成立时的数学命题**：项目目前的`Σ_u`由重复预设姿态估计，会混入同姿态下的正常手部运动，而且编码器残差是在原训练批次上估算的。因此目前的`R_k`只是“条件局部风险估计”，不具备已验证的真实概率覆盖率，更没有非线性全局可达或抓握安全保证。`A`含有缩放控制通道，`R_k`的单位更准确是“米等效任务特征量”，不是纯指尖位置误差。

当校准足够可靠时，`risk_policy: enforce`选择满足投影阈值和`R_k≤risk_budget_m`的最小k；无合格k时返回候选中风险最小值并记录`risk_feasible=False`，不会悄悄宣称满足要求。`hard_hold_risk_m`默认关闭。若开启，只在执行模式下针对高风险指令保持原有指令，同时上报hold状态。

## 3. 结构与修改文件

- `src/retargeting/uncertainty_model.py`：协方差载入、正半定检查、回归传播与重复姿态统计。
- `src/retargeting/credible_contact_synergy.py`：任务-可靠性联合协同基、条件风险选维、观测接触门控、非线性误差复核、诊断数据。
- `src/retargeting/reachability_synergy.py`：为方案C提取可扩展的选维与残差触发接口，保留原C默认行为。
- `src/retargeting/optimizer.py`：方案D风险/接触/非线性验证指标。
- `src/main.py`：新增CLI；上一帧真实接触反馈接入算法；同步扩充CSV列。
- `configs/credible_contact_synergy.yaml`：**安全默认：风险只诊断、不干预**。
- `configs/credible_risk_enforced_experimental.yaml`：风险介入实验配置；现有协方差未经独立校准，**不可当成安全保障**。
- `configs/credible_no_uncertainty.yaml` 与 `configs/credible_no_guard.yaml`：消融。
- `configs/chm6_uncertainty_proxy.json`：来自同一左手设备190帧重复姿态的描述性协方差（含数据来源与限制说明）。
- `scripts/calibrate_synergy_uncertainty.py`：按采集批次重新估计代理协方差。
- `experiments/实验07_可信度协同方案对比/benchmark_credible_synergy.py`：五到六套相同24帧的离线诊断对照。
- `test/tests_20261012/test_credible_contact_synergy.py`：PSD、单位、概率不等式理想模型蒙特卡洛、接触去抖动、确实减少求解变量、关节耦合、限速、非线性护栏与安全保持测试。

## 4. 使用方法

均在工程根目录运行，安装原工程`requirements.txt`要求的Python依赖：

```bash
# 方案D：风险只诊断，仍按任务确定真正的协同维度
python -m src.main --input glove --sim none --steps 24 \
    --latent-model configs/latent_chm6_adaptive.json \
    --credible-contact-synergy \
    --credible-config configs/credible_contact_synergy.yaml \
    --latent-source sensor

# 必须有新鲜、独立的标定数据才适合科学评估风险门控
python scripts/calibrate_synergy_uncertainty.py \
    --samples '数据手套数据/records/chm6_calibrations/20260917_102742_G12LC040704_left/captured_samples.csv' \
    --out configs/chm6_uncertainty_proxy.json

# 全部离线方法对照（当前测量仅为预设标签，不含物理接触）
python experiments/实验07_可信度协同方案对比/benchmark_credible_synergy.py --steps 24

# 独立运行方案D功能与数学性质测试
python -m pytest -q test/tests_20261012/test_credible_contact_synergy.py
```

加入`--sim mujoco --task pinch`才能从仿真接触指标中观察接触状态转换。本次运行环境没有安装MuJoCo；**该分支目前只有合成接触字典单元测试，不是物理抓取验证**。另请注意项目的默认意图识别器在24帧中全部产生`NEUTRAL`，因此该批次没有触发PINCH/WRAP专属接触试验。

## 6. 论文所需补充、创新性边界

完成的不是新PCA/神经网络，也没有数据证明跨人跨设备泛化。新的研究命题是“**输入可靠性–任务可达性–接触风险三者共同决定最小活动协同维度及何时开放独立补偿**”。PCA、Jacobian、二阶矩风险界、事件触发和残差优化均有相关先例；其联合机制的学术原创性必须进一步与近年的异构手重定向方法对比，不能直接宣称首次提出或高创新性。

高优先级工作：

1. 真实**静止手指**重复采样、不同用户/设备的传感器噪声分解；留出设备及时间批次验证风险覆盖（现有数据不满足这一点）。
2. 采集连续自由屈曲/独立屈指、连续PINCH/WRAP，以及同步机器人关节编码器与指尖位姿，报告真实误差、置信区间和误差-活动维数前沿。
3. MuJoCo与真机接触/滑移实验：比较接触获取时间、滑移率、抓握成功率、丢失接触后的恢复率和过度动作。
4. 计算优化：解析Jacobian、局部SQP/QP、低频规划/高频控制分层；当前没有满足60Hz优化期限。
5. 确认CH-M6真机是否真实独立可驱动11路。6→11的`C`仅为软件假设，不能作为机械传动事实。

**摘要建议用语：** “提出一种将局部任务可达性、编码不确定性估计和接触状态纳入自由度分配的联合协同重定向原型，并以六类预设姿态验证其软件可行性；真实任务性能与不确定性覆盖率尚待独立验证。”
