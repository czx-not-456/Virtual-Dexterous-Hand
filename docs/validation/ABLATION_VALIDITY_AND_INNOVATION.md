# v1.3.2+ 研究有效性与创新性审查（基于上传的代码快照）

## 审查结论

- 实验01 Stage B：**可运行且有历史诊断结果**，但只有 24 条记录、6 个预设姿态，共享掩码重复不独立；评价软件教师控制量归一化 MAE；六姿态 bootstrap 仅探索性。不能证明抓握成功或泛化。不能把历史原模型和增强模型误称为只改变潜在维度的公平消融。
- 实验02–04：静态/动态映射及手套标定/任务对照，有历史数据；指标受任务、姿态和数据来源限定，缺少独立参与者测试与可靠物理真值。
- 实验05：存在 `SCHEME_B_VALIDATION.json`，但它只记录旧版 24 帧非 MuJoCo 诊断，没有独立物理抓握结果；不能把旧版配置验证当成新的完整 benchmark。
- 实验06–08：存在离线 JSON 输出，主要为固定的 24 条姿态软件标签或运行时间指标；输出不是触碰/拿取成功率。应对比同一种训练数据、同一控制器和真实可达雅可比条件。
- 实验09：MuJoCo 五方法成对驱动脚本与默认 360 帧诊断工作簿存在，但当前包**没有完整 stageC_summary.csv 与对应 CSV 序列**。需实际运行并保存，才算完成性能对比。
- 实验10：有稳定性命令脚本；若缺少实际多运行原始跟踪数据，不应将单条时间轨迹或稳定代理当作可靠实验结论。

## 本次真正修改与实验可证性

1. 新增力验证（无效候选接触不会被误计）、每指/指尖双阈值与进出帧时序机制；控制/评估信号**严格分离**。
2. 保留历史物理成功代理的 raw-force 判据，而不把滤波状态当作抓稳真值。
3. 新增 `experiments/benchmark_contact_detection.py`：四方法、配对合成 episode、多指标、bootstrap；它只验证特定噪声模型中的检测稳定性，不代表真实抓握。
4. 修复打包中 `#Uxxxx` 非正常中文文件名及 `experiments/benchmark_*` 兼容导入路径。

## 最小完整科学验证方案

**分数据**：训练、阈值调节、最终盲测按人/采集会话/物体分组划分；不同受试者至少多批次，避免一段连贯运动帧横跨训练测试。已审查过的 24 姿态不再算盲测。

**主比较**：raw 几何 / 力阈值 / 纯时序 / 力+时序（本次）。*任务层面* 再对比原映射、固定 PCA4、方案 C、方案 D、方案 E、C/D/E 各关键组件的 ablation，不把“方法不同但调参也不同”算严格消融。所有方法配对使用相同输入、故障掩码、物体初态、摩擦与控制频率；记录并匹配计算开销。

**主终点**：有标签真实接触事件的 precision/recall/F1、检测延迟、每秒状态误翻转数；抓握层面是**物体自由释放后的相对位姿保持率**、滑移/滑落、接触力、穿透、恢复耗时。当前固定底座不能证明真实拿起搬运；必须另定义能实现的任务成功条件。

**统计分析**：预注册主要终点、阈值、停止规则；以独立会话/物体/采集者为统计单位做配对 bootstrap 或层次模型，报告 95% CI 与效应量；对关键场景检查负效应，不用“多个 seed 的同一片段”充当独立人类样本。

## 创新贡献边界

接触力阈值和滞回、防抖本身是常规工程技术，**不能单独主张学术创新**。现有 B/C/D/E 可能形成系统层面创新，但需要与最近相关研究对齐、有明确定义的独特算法机制和独立强基线。建议重点研究“基于传感器可信度 + 任务可达性 + 接触阶段的联合约束映射”，采用明确的分量消融和实时可行性/稳定性安全边界；目前不能宣称已验证显著领先。

## 历史数字：到底有没有改进？

下表直接抄录仓库已有 JSON 结果（单位：度，越低越好；时间单位：毫秒，越低越好）。**各研究阶段的独立采集/推理设置不完全相同，不应跨阶段做显著性排名。**

## 与近年研究对齐，避免夸大新颖性

- Chendong Xin 等，*Analyzing Key Objectives in Human-to-Robot Retargeting for Dexterous Manipulation*，IEEE Robotics and Automation Practice，2026：已系统进行人手映射目标项的现实消融。https://doi.org/10.1109/RAP.2026.3656110
- Zihao Yang 等，*Dexterous Robot Manipulation from Human Demonstrations via Contact-Anchored Retargeting and Residual Policy Learning*，2026：接触结构约束和残差修正已在研究中出现。https://arxiv.org/abs/2609.24093
- I. Spott 等，*An Experimentally Validated Hybrid Control Strategy for Robust Contact Detection and Force Regulation*，CCTA 2026：接触迟滞缓解开关抖动已有类似工作。https://doi.org/10.1109/CCTA62090.2026.11684304

**更有希望的可验证贡献方向**：以同一个物理任务误差约束，将 `传感器可信度 -> 可达方向选维 -> 接触状态 -> 安全残差` 设计成统一的有界控制决策，而非简单叠加四个开关。提出假设、给出算法约束和失败条件，再用同等预算的单因素/二因素消融及独立被试/物体验证。此部分属于**后续研究方向，并非此次已实现并证明的创新方法**。
